# Friday Night Fights - Releases

Public download releases for Friday Night Fights (uXa). The uXa Launcher installs and updates the game from here.

- Client: `FNF_Client_Win64_<version>.zip`
- Dedicated server: `FNF_Server_Win64_<version>.zip`

No source code lives in this repository. Get the launcher from https://github.com/uXa-Sloppy/uXa-Launcher/releases/latest
